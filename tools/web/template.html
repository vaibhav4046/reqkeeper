THE THEME · DORAHACKS KEEPERHUB 2026
“KeeperHub executes — deterministically, on demand, with full control and an auditable record. Agents are probabilistic by design. Onchain value transfer does not forgive that, ask an agent to move funds and it reinterprets what you meant, at the moment it matters most, every single time. KeeperHub removes the reinterpretation, your agent composes a workflow through our MCP server, you review it, you dry run it without touching the chain, and then that exact workflow executes. Nothing is inferred at execution time.”
— DoraHacks & KeeperHub Hackathon Brief
Why ReqKeeper is the #1 Contender for KeeperHub:
ReqKeeper turns KeeperHub from a low-level execution engine into an institutional-grade B2B settlement pipeline. It grounds every payment in a cryptographically signed Request Network invoice, resolves the fatal 24-hour key expiry vulnerability that causes agents to double-spend after daily wakeups, and enforces a local What-You-See-Is-What-You-Sign (WYSIWYS) calldata gate that halts dirty or tampered bytes before touching KeeperHub or spending gas.

5-LAYER DEFENSE ARCHITECTURE

How an invoice travels safely from an autonomous AI agent to final on-chain settlement without risk of reinterpretation or double payment.

LAYER 01
Invoice Ingestion
Derives obligation identity from the Request invoice, recovers secp256k1 payer/payee signatures, and establishes immutable anchor block.
✓ Malicious gateway rejected
LAYER 02
Standing Policy Gate
Enforces spend caps, fee proxy allowlist, token decimal precision, and destination sanity before proposing any payment.
✓ Refuses out-of-bounds at 0 gas
LAYER 03
Fenced Reservation
SQLite WAL transactional outbox with immediate transactions and fencing generations ensures exactly one worker process holds the lock.
✓ 50 workers → 1 payment
LAYER 04
WYSIWYS Calldata Gate
Decodes approved ABI calldata, validates parameters against policy ceilings, re-encodes locally, and byte-compares.
✓ Dirty bits & selector hacks killed
LAYER 05
KeeperHub Execution & Log Corroboration
Dispatches through KeeperHub REST (/api/execute/contract-call) or MCP server (app.keeperhub.com/mcp), and verifies Sepolia ERC20FeeProxy logs.
